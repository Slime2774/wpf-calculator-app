# WPF Calculator App & Logic Library

Приложение-калькулятор, разработанное на платформе WPF с разделением логики интерфейса и математических вычислений.

## 🏛 Архитектура проекта
Проект разделен на два независимых модуля для соблюдения принципа разделения ответственности (Separation of Concerns):
* **WpfLibrary** — изолированная библиотека классов (`.dll`), содержащая чистую математическую логику вычислений. Не зависит от UI-платформы.
* **WpfCalculator** — графический интерфейс пользователя (UI), разработанный на WPF с использованием XAML. Отвечает за отображение и обработку нажатий кнопок, вызывая методы из `WpfLibrary`.

## 🛠 Технологии
* Язык программирования: C#
* Платформа: .NET, WPF (XAML)
* Архитектура: Модульная (Class Library + Executable App)
